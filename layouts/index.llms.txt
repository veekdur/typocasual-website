## A note on `growth`

Every frame carries a `growth` value from 0 to 1. It is this site's own concept: how long
the frame has been out in the weather, not a rating or a ranking. It drives how much moss
covers the frame — 0 is bare concrete, 1 is buried. The same value appears on essays.
Frames are filtered by `kind`: {{ range $i, $f := $sheet.filters }}{{ if $i }}, {{ end }}`{{ $f.id }}`{{ end }}.
