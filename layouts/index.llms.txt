# typocasual

> {{ site.Params.description }}

A static site served by a Cloudflare Worker. The front page is {{ len $frames }} frames, one
typeface each, showing why the face is used and where it appears. Behind it are
{{ len $posts }} {{ cond (eq (len $posts) 1) "essay" "essays" }}. No server-side rendering, no CMS,
no database, no build step beyond Hugo.

Tagline: {{ site.Params.tagline }}

## Machine-readable

- [data.json]({{ "/data.json" | absURL }}) — the frames and the outbound links. The source of truth for the front page.
- [data.schema.json]({{ "/data.schema.json" | absURL }}) — JSON Schema describing the shape of data.json.
- [Essays]({{ "/posts/" | absURL }}) — longer pieces, one Markdown file each.
- [AGENTS.md](https://github.com/veekdur/typocasual-website/blob/main/AGENTS.md) — how to edit this site.
- [DESIGN.md](https://github.com/veekdur/typocasual-website/blob/main/DESIGN.md) — the design rules and their reasons.
