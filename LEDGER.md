# LEDGER.md — revision history

What changed, when, and why. Newest last. An entry is added when a change alters the
**design, the structure, or the content model** — not for typo fixes.

An agent making a substantial change should append an entry. Keep it to: what changed, why,
and anything that would be non-obvious to whoever reads it next.

---

## 2026-09-12 — Build the site

**Commit** `3541097` — Add typocasual contact sheet

First working version. A Cloudflare Worker serving static assets, with a front page shaped
like a photographic contact sheet: 20 frames of generated concrete plates, type specimens and
text cards, with growth-driven moss and a lightbox. Content in a single `data.json`. A
validator and a GitHub Actions workflow were added at the same time.

Why: the owner asked for a front page, liked a brutalist-and-moss direction, and wanted
markdown posting to come later.

---

## 2026-09-12 — Fix the schema fallthrough

**Commit** `1e8099c` — Publish the content schema and stop falling through to the SPA

`data.schema.json` sat at the repo root, so it was never uploaded, and `/data.schema.json`
hit the single-page-app fallback and returned HTML. Moved into `public/` and pointed
`data.json` at it with `$schema`. Also disabled preview URLs.

Why: `llms.txt` promised a schema URL that returned HTML. An agent fetching it got garbage.

---

## 2026-09-12 — Add Hugo and essays

**Commit** `5f0393c` — Add an essay blog, built by Hugo

The owner asked for a blog and chose Hugo. `public/` became build output and is now
gitignored; source moved to `static/`, `layouts/`, `content/` and `archetypes/`. `llms.txt`
is now generated by `layouts/index.llms.txt` so it cannot drift from the content. The SPA
fallback was replaced with a real 404 page, now that real pages exist. Added an essay index,
RSS, sitemap and robots.txt.

Why: "I just want to type markdown and post it."

## 2026-09-12 — Redesign: the frames become typefaces

**Uncommitted at the time of writing**

The owner reviewed the site and rejected most of it. The feedback, and what was done:

| Feedback | Change |
| --- | --- |
| "The green stuff getting in the way of the viewport" | Removed the fixed overgrowth layer entirely — vines, spores and the moss bank. |
| "It's not actually integrated with the content, like moss would be" | Moss now grows inside the bottom padding of each slab, clipped to that slab, so it cannot cross text. Per-slab `--creep`. |
| "The title is humongous" | The wordmark rendered at 160px. Now about 74px maximum. |
| "Four different subtitles for the title" | Cut the kicker, both ledes and the epigraph. One line survives, plus the vault welcome. |
| "I don't understand the frames" | Frames are now typefaces: one per face, showing a live specimen, why it is used and where. |
| "I do want to stick to the fonts I mentioned" | Added Fira Sans and Lexend Deca to the existing four. Six faces, six frames. |
| "The colophon, I don't know what that is" | Removed. It is a plain footer now. |
| "Elsewhere being there twice" | The link cards stay; the second block in the footer is gone. |
| "It doesn't need the INSIG one" | Removed. |
| "Growth, 55%. What does that mean?" | Removed from the essay meta line. |
| "The contact sheet I can't click on" | The lightbox is gone. The frames explain themselves, so there is nothing to expand. |

**The measurement that drove the moss change.** The old pages were analysed with Apple Vision
and pixel sampling:

| | green | aesthetic score | classification |
| --- | --- | --- | --- |
| The reference the owner liked | 88% | 0.24 | a designed page |
| The old home page | 20% | 0 | a screenshot |
| The old Elsewhere block | 76% | −0.11 | `outdoor / hill / land / sky` |

Apple Vision read the Elsewhere block as a photograph of a hillside. Only the word `ELSEWHERE`
survived text recognition. Volume was never the problem — placement was. The reference is
88% green because there the green is the *field*; the old page was green *on top*.

Also in this change: Moonlit returned to a deep green field (matching the reference); added
`DESIGN.md`, `CONTEXT.md` and this file; `check.mjs` now verifies that every face a frame
names is actually requested by the fonts link; and the validator's data contract was
rewritten for the new frame shape.

## 2026-09-12 — Review pass: navigation, intro, plates, moss

**Delegated.** Both tasks were coded by `deepseek/deepseek-v4.1-flash` through Command Code,
brokered by `agentctl` (two runs, audited under `~/.agentctl/runs/`). Reviewed and verified
visually by the parent — first time the site has been reviewed with actual vision, using
headless-Chromium renders in both themes.

| Finding | Fix |
| --- | --- |
| `/posts/` was unreachable from the front page — the rail label was a `<span>` | An "Essays" link now renders on the home and essay pages |
| Vault scaffolding was live: "Links to Cool Stuff" (with the INSIG link) and "Appearances in the Wild", a heading whose body admitted it had no content | Removed. The intro now ends at "Contact me here!" |
| "Essays" printed twice on `/posts/` (kicker + H1) | Kicker removed |
| Essay plates sat on a near-black ground in Sunlit | The plates' sky gradient was replaced with a `--plate-ground` token — `#0d1a12` in Moonlit, `#e5e2da` in Sunlit — so plates now sit directly on the page field |
| The moss read as a bevel, not moss: technically in the joint, but a smooth glow with no character | Rebuilt as a fringe: a thin base band plus overlapping radial-gradient clumps, tiled at co-prime widths, phased per slab (`--moss-x` from `--creep`) |

**Process note.** The moss finding only surfaced because the redesign was finally *looked at*.
Every check before this one was structural. The lesson is recorded in `AGENTS.md`:
`check.mjs` can verify moss is clipped to its slab, but only eyes can verify it reads as moss.
